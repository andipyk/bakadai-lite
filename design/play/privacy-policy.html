Kebijakan Privasi Bakadai Lite

Berlaku sejak 19 November 2026

Ringkasan

Bakadai Lite adalah aplikasi kasir dan stok barang yang menyimpan semua data di perangkat Anda. Kami (pengembang) tidak mengumpulkan, menyimpan, atau menjual data Anda. Aplikasi tidak memuat iklan, analitik, atau pelacak.

Data yang disimpan di perangkat

Barang, harga, stok, transaksi, kontak pembeli/vendor, staff, pengeluaran, foto barang, dan pengaturan toko disimpan di penyimpanan internal aplikasi di HP Anda. Data ini tidak dikirim ke kami.

Foto barang dikecilkan di perangkat dan informasi lokasi (EXIF/GPS) di dalam foto dibuang sebelum disimpan.

Sinkron ke server (opsional)

Jika Anda mengisi alamat server di menu Server & Sinkron, aplikasi mengirim dan menerima data toko ke server tersebut melalui HTTPS. Server itu milik Anda atau pihak yang Anda pilih, bukan milik kami, sehingga pengelolaan data di sana mengikuti kebijakan pemilik server.

Izin perangkat

  • Internet: hanya untuk sinkron opsional dan printer jaringan.
  • Bluetooth / Perangkat sekitar: hanya untuk menyambung ke printer struk yang sudah Anda pasangkan.
  • Kamera: hanya untuk scan barcode barang. Gambar kamera dibaca langsung di HP dan tidak disimpan atau dikirim ke mana pun.

Menghapus data

Semua data ada di perangkat Anda. Menghapus data aplikasi atau mencopot pemasangan Bakadai Lite akan menghapus semuanya dari HP. Data yang sudah disinkronkan ke server Anda dihapus melalui server tersebut.

Anak-anak

Bakadai Lite ditujukan untuk pemilik dan staf usaha, bukan untuk anak-anak.

Kontak

Pertanyaan tentang kebijakan ini dapat dikirim melalui email pengembang yang tercantum di halaman Bakadai Lite di Google Play.
